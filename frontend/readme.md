My Scoring logic came from distance from target budget the absolute value of the difference between target and price of listing, similar to how we think about "over/under pricing" when dealing with negotiations. Combined that number with date time recency which is just the difference of now and when the listing was posted. This took into account for a 30 day decay so anything above that gets filtered out by my math.max function as zero. These two numbers were added together and divided by 2 for the average or mean score.
